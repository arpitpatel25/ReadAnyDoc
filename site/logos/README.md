# Logos

Shown next to well-known names on the website and docs by `scripts/brand_logos.py` (run at deploy). They name the
products we work with or compare against; each belongs to its owner.

- SVGs: Simple Icons (CC0), coloured with each brand's colour: Claude, Anthropic, OpenAI, Docker, GitHub, Python,
  PyPI, Mistral AI, Hugging Face, Ollama, Cursor, Windsurf, LangChain, FastAPI, Kubernetes, Google Gemini,
  Model Context Protocol, AWS, Microsoft Azure.
- `reducto.svg`: the mark from reducto.ai's own logo.
- PNGs (64 px): vLLM (its repository's logo), LlamaIndex, Docling, Unstructured and Ai2 (olmOCR) from their GitHub avatars.

To add a name, put the logo here and add a line to `BRANDS` in `scripts/brand_logos.py`.
