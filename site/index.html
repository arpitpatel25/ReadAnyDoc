Reducto's product, without the lock-in.

Same API as Reducto

Point Reducto's own SDK at your ReadAnyDoc server. Parse, extract, split, classify, edit, jobs and webhooks answer in the same format, so the code you have keeps working.

Your model, your account

Documents go straight to the model provider you pick, under your own key. Claude Haiku 5.5 by default, and any Claude, OpenAI or self-hosted model when you want it.

A fraction of the price

$0.003 to $0.005 a page with the full engine, or $0.001 to $0.002 with the model alone. Reducto charges $0.01. Nothing is added on top of your model bill.

One library for every document task.

Parse

Pages become typed blocks (text, tables, form fields, figures) with their positions, plus Markdown for your LLM or search index.

Extract

Hand it a pydantic class or a JSON schema. Get it back filled in, with a citation for every value.

Split

Find where each document starts and ends inside one combined PDF.

Classify

Label documents by type, with the text that supports the label.

Edit

Fill in PDF forms, including flat and scanned ones.

Jobs and webhooks

Send large batches in the background and get notified as each one finishes.

What happens to each page.

The model does the reading. ReadAnyDoc does everything a model alone does not: it checks the work, finds where every value sits, and returns it in the shape you asked for.

  1. Open

    PDF, scan, photo, Word, Excel, PowerPoint or email, split into pages.

  2. Look

    A small layout model on your CPU finds tables, forms, figures and headers.

  3. Read

    Claude reads each page. Scans get zoomed re-reads that must agree before a digit changes.

  4. Check

    Table grids and printed totals are verified without a model. Problems become warnings.

  5. Cite

    Every word and table cell is matched to its position, so every value can show its source.

Running in a minute.

Use it as a Python library with no server at all, or run the server and call it from any language. Switching from Reducto is one line.

# as a library
import readanydoc

result = readanydoc.parse("statement.pdf")
invoice = readanydoc.extract("invoice.pdf", schema=Invoice)

# or with Reducto's SDK, pointed at your server
client = Reducto(api_key="...",
                 base_url="http://localhost:8000")

How we built it.

We tried to replace a purpose-built document model with an off-the-shelf one. Four days, more than 5,300 benchmark pages and 272 experiments. Most of our ideas failed, and the biggest surprise came at the very end. Here is everything that happened.

  1. Chapter 1

    The bet

    Leave the model untouched and build the layer around it, so every new model is a free upgrade.

  2. Chapter 2

    We measured before we built

    Plain Haiku was already level with Reducto on reading. That changed everything that came next.

  3. Chapter 3

    Our first layer made the model worse

    Reading every page twice and refereeing scored below one plain read, at nine times the price.

  4. Chapter 4

    We stopped trusting our own numbers

    Cost was overstated four times, the AI judge misread numbers, and small samples flattered us.

  5. Chapter 5

    272 ideas, and most of them failed

    What the model does not give you: layout, forms, checks and citations. 75 ideas were dropped outright.

  6. Chapter 6

    Meanwhile, making it usable in real work

    Citations, confidence, long contracts, handwriting and large schemas, built from what teams ask for.

  7. Chapter 7

    Then the full benchmarks overturned our results

    On all 1,000 tables our lead disappeared. Only the complete benchmarks count.

  8. Chapter 8

    Where we landed

    Ahead on reading, level on tables and forms, behind on layout and speed, at half the price.

Questions.

Is it really free?

Yes. ReadAnyDoc is Apache-2.0. You pay only your model provider for the calls it makes, and every result tells you what those calls cost.

Which models can I use?

Any Claude model, OpenAI models, or a model you host behind an OpenAI-compatible server such as vLLM. Choose the model, effort and request options per call. The benchmarks use Claude Haiku 5.5, with Sonnet 5.5 for handwriting.

Is it as good as Reducto?

Ahead on reading text, level on tables and forms, behind on page layout, formulas and speed. The table above links to every benchmark and the full method.

Where do my documents go?

To your machine and to the model provider you configure, under your account. Nothing comes to us. With a self-hosted model, nothing leaves your network.

Do I need to run a server?

No. Install the library and call it from Python. Run the server only if you want Reducto's API or need to call it from another language.

What is the difference between engine and model only?

Model only sends each page to the model once: cheapest and fastest. The engine adds layout, form fields, table checks, zoomed re-reads of scans and word-level citations, for two to three times the model cost.
