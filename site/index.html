ReadAnyDoc turns PDFs, scans, photos and Office files into clean, typed data. Every value comes with the exact place on the page it was read from. Open source, and it runs on your own model account.

One tool for every document task

Parse

Every page becomes typed blocks (titles, text, tables, form fields, figures) with their positions, plus Markdown for your LLM or search index. Headers, footers and page numbers are marked, not mixed in.

Extract

Give it a pydantic class or a JSON schema and get back an instance of it. Each value cites the words it came from, so a reviewer can check it in one click. Long documents are read in parts and merged.

Split, classify, edit

Find where each document starts in a combined PDF, label documents by type, and fill in PDF forms. The same API as Reducto, so existing code keeps working.

Your types in, your types out

Describe what you need as a normal Python class. ReadAnyDoc reads the document, fills the class, and tells you where each value is on the page. No server needed.

Prefer an API? Run readanydoc serve or the Docker image and call it over HTTP from any language.

from pydantic import BaseModel
import readanydoc

class Invoice(BaseModel):
    number: str
    issued: str
    total: float

out = readanydoc.extract("invoice.pdf", schema=Invoice)

out.data.total             # 1575.0
out.citations["total"]     # page 1, box around "£1,575.00"
out.usage.cost_usd         # what the model calls cost

Pick how much work it does

Engine default

The model reads each page, then ReadAnyDoc adds layout, form fields, table checks, zoomed re-reads of scanned digits and word-level citations. Handwriting goes to a stronger model.

About half Reducto's price per page.

Model only

One model read per page and nothing else. Cheapest and fastest, and already level with Reducto on reading text and tables.

A fifth to a ninth of Reducto's price per page.

Every model is your choice: any Claude model, OpenAI models, or a model you host yourself behind an OpenAI-compatible server. Set the effort and any provider option per call. Benchmarks above use Claude Haiku 5.5.

How it works

Each page passes through the same steps. Nothing the model wrote is changed without independent evidence, like a second zoomed read that agrees or the PDF's own text.

  1. OpenDetect the file type, decrypt, split into pages. PDF, images, Word, Excel, PowerPoint, email.
  2. LookDigital or scanned, rotated or not, and where the tables, forms and figures are, using a small layout model on your CPU.
  3. ReadThe vision model reads the page. Scanned pages get zoomed re-reads; a digit changes only when two reads agree.
  4. CheckTable grids and printed totals are checked without a model. Problems become warnings, not silent errors.
  5. LocateEvery word and table cell is matched to its position, so every value can cite its source.
  6. DeliverBlocks, Markdown, chunks for search, or your schema filled in. The same JSON shape as Reducto.

Already on Reducto? Change one URL

Run the ReadAnyDoc server and point Reducto's own SDK at it. Parse, extract, split, classify, edit, async jobs, webhooks and citations all answer in Reducto's format.

Your documents go only to the model provider you choose, under your own account.

# docker compose up   or   readanydoc serve
from reducto import Reducto

client = Reducto(
    api_key="...",
    base_url="http://localhost:8000",
)
result = client.parse.run(input=upload.file_id)
