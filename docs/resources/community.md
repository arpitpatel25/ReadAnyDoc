# Community and support

| You want to | Go to |
|---|---|
| Ask a question, get help with a document type, share a setup | [GitHub Discussions, Q&A](https://github.com/arpitpatel25/ReadAnyDoc/discussions/categories/q-a) |
| Suggest a feature or a model to support | [Discussions, Ideas](https://github.com/arpitpatel25/ReadAnyDoc/discussions/categories/ideas) |
| Show what you built with it | [Discussions, Show and tell](https://github.com/arpitpatel25/ReadAnyDoc/discussions/categories/show-and-tell) |
| Report wrong output, an error or a crash | [Open an issue](https://github.com/arpitpatel25/ReadAnyDoc/issues/new/choose) |
| Report a security problem | [Private security advisory](https://github.com/arpitpatel25/ReadAnyDoc/security/advisories/new) (not a public issue) |
| Hear about releases | Watch the repository: *Watch, Custom, Releases* on [GitHub](https://github.com/arpitpatel25/ReadAnyDoc) |
| Contribute code, a benchmark or a profile | [Contributing](contributing.md) |

When you ask about a wrong result, say which mode and model you used, the ReadAnyDoc version
(`python -c "import readanydoc; print(readanydoc.__version__)"`) and, if you may share it, attach a page that shows
the problem. Remove anything private first.
